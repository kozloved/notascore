# NotaScore

AI-powered Audio to Sheet Music SaaS.

Domain:
https://notascore.com

Features:
- Audio upload
- Solo transcription (Basic Pitch, CPU)
- Polyphonic transcription (YourMT3 via mt3-infer 0.2.0, remote GPU)
- MusicXML export
- MIDI export
- PDF sheet music export

Hosting:
- Site (CPU): cheap VPS + Cloudflare Tunnel — audio2score-week4/deploy/VPS.md
- Polyphonic GPU: Vast.ai

Status:
MVP in development.

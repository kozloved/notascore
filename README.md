# NotaScore

AI-powered Audio to Sheet Music SaaS.

Domain:
https://notascore.com

Features:
- Audio upload
- Fast transcription (Basic Pitch)
- Quality transcription (MR-MT3)
- MusicXML export
- MIDI export
- PDF sheet music export

Status:
MVP in development.

Deploy:
Cloudflare Tunnel in front of the Docker stack — see `audio2score-week4/deploy/README.md`.

# Production score QA worksheet

Use this after a live production smoke job completes. The automated matrix
only proves infrastructure, routing, raw MIDI identity, and artifact
retrieval. Notation quality is a musician review.

Copy a block per fixture. Do not invent an automated “beautiful notation”
score from this sheet.

Federation (separation / stem AMT / fusion) stays **OFF** for this baseline.

---
